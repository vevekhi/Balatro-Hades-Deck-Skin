
# Balatro-Hades-Deck-Skin
A Balatro Mod that adds a Friends of Jimbo style deck skin based off of the popular indie roguelike game "Hades". Adds a deck skin for the Heart Suit

King of Hearts - Hades
Queen of Hearts - Nyx
Jack of Hearts - Zagreus
