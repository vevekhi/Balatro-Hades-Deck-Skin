# Balatro-Hades-Deck-Skin
A Balatro Mod that adds a deck skin based off of the popular indie roguelike game "Hades". Adds a deck skin for the Heart Suit

Requires Steammodded {https://github.com/Steamodded/smods?tab=readme-ov-file}
follow the steammodded instilation process and drop in the unzipped folder in the 'mods' folder

King of Hearts - Hades

Queen of Hearts - Nyx

Jack of Hearts - Zagreus
